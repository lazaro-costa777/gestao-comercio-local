# 🛒 Gestão de Comércio Local

Plataforma de gestão de catálogo e pedidos focada na digitalização de pequenos comércios e prestadores de serviço locais.

Projeto desenvolvido de forma autônoma como portfólio prático durante a graduação em **Bacharelado em Sistemas de Informação (BSI)** no **Instituto Federal de Sergipe (IFS) - Campus Lagarto**.

---

## 🎯 Objetivo do Projeto

Resolver as principais dores de gestão e atendimento do comércio regional, oferecendo:
- **Catálogo Digital:** Visualização simples de produtos/serviços atualizados em tempo real.
- **Envio de Pedidos:** Integração direta com WhatsApp para checkout rápido sem fricção.
- **Painel Administrativo:** Controle enxuto de estoque, vendas e cadastro de produtos.

---

## 🛠️ Tecnologias Planejadas

### Fase 1: Protótipo e Fundamentos (Ano 1-2)
- **Frontend:** HTML5, CSS3, JavaScript (ES6+) / React.js
- **Backend:** Node.js / Java (Spring Boot)
- **Banco de Dados:** PostgreSQL / MySQL
- **Versionamento:** Git e GitHub

### Fase 2: Módulo SaaS & Nuvem (Ano 3-4)
- **Autenticação:** JWT / Supabase Auth
- **Infraestrutura:** Vercel / AWS
- **Recursos Avançados:** Dashboard analítico e integração com IA para atendimento automatizado
